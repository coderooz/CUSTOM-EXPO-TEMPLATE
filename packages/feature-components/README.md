# @coderooz/feature-components

Reusable component library for Coderooz Expo projects.

## What's Included

### UI
- Button — primary, secondary, outline, ghost, danger variants; sm/md/lg sizes; loading state
- Input — text input with label, error, helper text, left/right adornments
- PasswordInput — password field with visibility toggle
- SearchInput — search field with icon and clear button
- Textarea — multi-line text input
- Select — dropdown select with modal picker
- Checkbox, Radio, Switch, Chip

### Interactions
- Dialog — modal dialog with title, description, actions
- BottomSheet — draggable bottom sheet via @gorhom/bottom-sheet
- Snackbar — toast notification with action button
- Menu — dropdown action menu

### States
- LoadingScreen, Skeleton, EmptyState, ErrorState, OfflineBanner, PermissionGate

### Layouts
- Screen, ScrollableScreen, CenteredScreen, SplitLayout, Section, Card, Divider, Stack (HStack/VStack), Grid
